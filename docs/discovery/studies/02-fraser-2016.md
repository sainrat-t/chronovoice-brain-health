## En une phrase

Sur de courtes descriptions d'image, un classifieur distingue les personnes atteintes d'Alzheimer des témoins avec plus de 81 % de précision. L'analyse factorielle fait ressortir **4 familles d'atteinte** : sémantique, acoustique, syntaxique et informationnelle.

## À guetter pendant la lecture

- **H1 : les 4 facteurs.** Sémantique, acoustique, syntaxique, informationnel. Ce découpage pourrait structurer nos agents (un extracteur par famille ?) ou nos indicateurs du dashboard. Note quelles features tombent dans quel facteur.
- **H2 : MATTR.** Est-il dans les features ? Avec quelle(s) taille(s) de fenêtre ? Quel poids dans le classifieur ?
- **H4 : pauses et hésitations.** Comment les pauses sont-elles mesurées (seuils, outil d'alignement) ? Les « euh » sont-ils dans les transcriptions ?
- **H6 : pronoms et mots vides.** Le ratio pronoms / noms et les mots vides sont-ils dans le facteur sémantique ? Quel sens de l'effet ?
- **Plusieurs échantillons par personne** (240 pour 167 patients) : les visites répétées sont-elles exploitées ? Les échantillons d'une même personne sont-ils séparés entre entraînement et test (sinon, résultat gonflé) ?
- **H10 : transposition.** Anglais, description d'image : qu'est-ce qui survit dans un récit de vie libre en français ?
