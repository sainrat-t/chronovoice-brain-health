# frontend/ — Clinician Dashboard

Vide pour l'instant. Le scaffold se fait à la phase dashboard, une fois les étapes backend validées :

```bash
npm create vite@latest . -- --template react-ts
npm install
npm install -D tailwindcss @tailwindcss/vite
npm install lucide-react recharts
```

Vues prévues : vue d'ensemble patient (Brain Health Index), courbes longitudinales sur 6 mois, comparateur de séances avec passages surlignés, volet facteurs contextuels, export de la synthèse clinique.
